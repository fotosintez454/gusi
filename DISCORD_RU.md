# Статус «Играет в ОКНО» в Discord

## Что уже сделано
Игра умеет подключаться к локальному Discord RPC и задавать Rich Presence: текущее занятие, день, сезон, ранг и длительность с запуска.
Это не бот и не self-bot. Discord-токен и пароль не нужны. Дополнительные DLL не нужны. При отсутствии или перезапуске Discord игра продолжает работать; подключение повторяется в фоновом потоке.

## Что нужно от разработчика игры
1. Открой https://discord.com/developers/applications и создай приложение с именем «ОКНО».
2. В General Information скопируй **Application ID**. Это публичный числовой идентификатор, не токен и не Client Secret.
3. Открой discord_app_id.txt рядом с EXE и замени 0 на этот ID, только цифры в одной строке.
4. Запусти настольный Discord и перезапусти игру.
5. В Discord включи отображение текущей активности в настройках конфиденциальности активности. Название игры берётся из имени созданного приложения.

Обновление сведений занимает до 15–20 секунд. Работает с настольным клиентом Discord; вкладки браузера недостаточно.
Чтобы выключить, снова поставь 0 в discord_app_id.txt и перезапусти игру.

## Если статуса нет
- Проверь, что указан Application ID (обычно 17–20 цифр), а не секрет приложения.
- Проверь запуск настольного клиента и разрешение показа активности.
- Используй обычную установленную Windows-версию Discord. Не запускай игру и Discord с разными уровнями прав.
- Без Application ID подробный статус не активируется. Никакой чужой идентификатор автоматически не подставляется.

Передаваемые данные: название занятия, игровой день, сезон, ранг, время начала сеанса и идентификатор процесса, необходимый RPC. Деньги, имя Windows, файлы сохранения и их путь не публикуются.

Документация протокола: https://docs.discord.com/developers/topics/rpc
Реальный статус в клиенте здесь не проверен: нет Application ID и Windows-клиента Discord. Это ограничение проверки, а не обещание готового подключения к вашему аккаунту.
