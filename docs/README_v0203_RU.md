# ОКНО 0.20.3 — дома, лестницы, гаражи и Discord

Распакуйте весь архив в новую папку. Запуск: START.bat / OKNO.exe.
Резервный программный режим: START_SAFE.bat / OKNO_SAFE.exe.
Сохранения 0.20.0–0.20.2 совместимы: прежний OKNO_020.save, формат 17. Новая игра для патча не обязательна.

## Геометрия домов
- У четырёхэтажных панелек убрана ошибочная пятая площадка лифта на крыше. Высота и цель лифта из старого сохранения ограничиваются последним настоящим этажом.
- У поручней есть стойки с опорой на настоящие ступени, а не на пустоту между маршами. Добавлена коллизия поручней в пятиэтажках, панельных домах и высотках.
- Устранены найденные щели между плитами пола, стенами и площадками. Нижние этажи лестничных клеток получили сплошное основание.
- Убраны невидимые этажные полы внутри пустой шахты: опорой там служит настоящая кабина.
- Панельные плиты теперь действительно обходят шахту, а не проходят сквозь неё.
- Закрыты вертикальные полосы вокруг фасадных окон панельных квартир.
- На верхнем этаже высотки сохранён настоящий лестничный проём; проверен спуск жителей с последнего этажа. Он не перекрыт сплошной плитой.

## Гаражи
Теперь 24 бокса: 16 прежних гаражей переработаны, добавлено 8 кирпичных на окраинах района. Металлические ворота, петли, рёбра, замки, таблички, наклонная крыша, водосток и кирпичные швы. У крыш есть опорная поверхность и коллизия стен.
Гаражи находятся на западной и восточной окраинах. Старые 16 открываются клавишей E. Новые 8 кирпичных принадлежат другим владельцам и заперты — это указано в подсказке.

## Производительность
Добавлено консервативное отсечение целого здания до обработки всех его окон и деталей. Предыдущая оптимизация сохранена. В программном режиме (включая SAFE) запуск и загрузка теперь выбирают 800×450 без сглаживания вместо тяжёлого 1920×1080; обычный GPU-режим не понижен. После загрузки разрешение можно изменить вручную в настройках. Замеры конкретных контрольных сцен — в PERFORMANCE_RU.txt; это CPU-тест программного рендера, а не обещание FPS на любом компьютере.

## Discord — важно
Поддержка Rich Presence добавлена, но для настоящего статуса требуется Application ID приложения Discord. Чужой или выдуманный ID в игру не вшит.
В discord_app_id.txt сейчас стоит 0: интеграция выключена и не мешает запуску игры.
Чтобы включить, впишите свой Application ID одной строкой и перезапустите игру. Подробная инструкция — DISCORD_RU.md.
Статус содержит занятие, день, сезон, ранг и время с запуска. Пароли, токены, имя пользователя Windows, путь к сохранению и координаты не отправляются. Обмен локальный, с установленным настольным Discord, в отдельном потоке, вне игрового кадра.
Подключение к настоящему Discord здесь не проверено: Application ID пользователя не предоставлен, Windows/Discord в среде нет. Проверены сериализация сообщений и сборка Windows-кода.

## Проверки
51212 новых проверок без ошибок, включая аудит доступных поверхностей квартир, лестниц и площадок всех этажей трёх типов домов. В проверенной сетке — ноль точек без нарисованной опоры; проверена опора стоек перил на ступени. Это не заявление, что невозможно найти ни одного визуального дефекта при любом ракурсе.
Полный регрессионный прогон завершён без ошибок. Диагностические нативные тесты собраны с O1; обычная Windows-версия — с O2, SAFE — с O1.
Оба Windows EXE собраны. Интерактивного запуска на Windows и проверки OpenGL-драйвера не было. Подробнее: QA_RESULTS_RU.txt. Текущие контрольные изображения — qa/v203.

Предыдущие возможности сохранены: качели/карусель (E — сесть/встать, Пробел — разогнать/остановить), сезонные следы, экономика и перенос предметов. История: docs/README_v0202_RU.md.
